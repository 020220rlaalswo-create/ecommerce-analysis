# Olist 분석 결과 및 비즈니스 제안

> **상태:** 실행 가능한 분석 코드가 준비되어 있습니다. 아래 문서는 실제 CSV 실행 뒤 `outputs/kpis.json`과 PNG 결과를 인용하여 확정하는 결과 보고서 템플릿입니다. 측정하지 않은 수치를 사실처럼 제시하지 않습니다.

## 1. 분석 질문
1. 월별 상품 매출과 주문 추이는 어떻게 변화하는가?
2. 어떤 카테고리가 배송 완료 주문의 매출을 견인하는가?
3. 배송 지연은 어느 지역에 집중되며 만족도와 어떤 관계가 있는가?
4. 관측 기간 내 재구매 고객의 비중은 얼마인가?

## 2. 지표 정의 및 분모
| 지표 | 정의 | 주의점 |
|---|---|---|
| 상품 매출 | 배송 완료 주문의 item price 합계 (BRL) | 운임/쿠폰/환불을 반영한 순매출 아님 |
| 평균 상품 주문액 | 배송 완료 주문별 상품 합계의 평균 | 결제 금액 평균과 다름 |
| 평균 배송 기간 | 실제 배송일 − 주문일, 배송 완료 주문 중 유효 기록 | 시간 단위 계산 후 일수 환산 |
| 배송 지연율 | 실제 배송일 > 예상 배송일 / 두 날짜 모두 있는 배송 완료 주문 | 결측 날짜를 정상 배송으로 간주하지 않음 |
| 관측 재구매율 | 완료 주문이 2회 이상인 고유 고객 / 완료 주문 고객 | 관측 종료에 따른 우측 검열, 고객별 추적기간 차이 |
| 리뷰 점수 | 주문별 리뷰 점수 평균 | 복수 리뷰를 주문 단위로 집계 |

## 3. 실행 후 확인할 시각화
- `outputs/01_monthly_revenue.png`: 월별 추이, 계절성 및 관측기간 양끝의 부분월 여부
- `outputs/02_category_revenue.png`: 상위 12개 상품 카테고리
- `outputs/03_order_status.png`: 주문 상태 분포
- `outputs/04_delivery_days.png`: 배송 소요일의 장기 꼬리
- `outputs/05_late_delivery_states.png`: 표본 100건 이상 지역의 배송지연율
- `outputs/06_repeat_customers.png`: 관측 기간 재구매 고객 구성
- `outputs/07_review_vs_lateness.png`: 지연 여부에 따른 평균 리뷰 점수

## 4. 비즈니스 실행 제안 (검증 전 가설)
**배송 품질:** 지연율이 높고 물량이 충분한 주를 우선 선정하여 물류사/판매자별 분해 분석한다. 배송 지연과 낮은 평가가 연관된다면 배송 예상일 정확도 및 배송 안내를 A/B 테스트한다.

**상품 구성:** 상품 매출 상위 카테고리를 찾되, 총매출과 주문당 매출, 주문수, 운임의 네 관점을 동시에 본다. 매출 상위가 이익 상위라는 뜻은 아니다.

**재구매:** 첫 구매 월별 코호트의 관측기간을 맞추고 재구매율을 비교한다. 동일 기간 고객별 최초 구매 후 30/60/90일 재주문 지표로 확장할 수 있다.

## 5. 한계와 주의
- **실제 방문→장바구니→결제 전환 퍼널 계산 불가:** 방문/장바구니 로그가 없음. 주문상태를 마케팅 퍼널로 명명하지 말 것.
- 취소/미배송 주문을 제외한 상품 합계는 재무상 확정 매출이 아니라 배송완료 기준 거래규모의 근사치.
- Olist 데이터는 2016–2018년 익명화 자료이며 현재 사업실적을 나타내지 않음.
- 리뷰-배송 관계는 상관관계이며 인과효과로 해석하지 않음.
- 사용자의 이전 로컬 분석 수치와 Kaggle 원본의 수치가 다르면 필터, 테이블 수, 날짜 기준, 중복 행을 점검할 것.

## 6. 채용 포트폴리오용 3문장 발표 예시
“브라질 이커머스 다중 테이블 데이터를 주문 단위로 통합하여 SQL/Python 분석 파이프라인을 설계했습니다. 일대다 조인에 의한 매출 중복 집계를 방지하고, 배송 지연·고객 재구매·상품 카테고리별 핵심 지표를 시각화했습니다. 결과를 바탕으로 배송 품질 관리와 재구매 측정 체계 개선을 위한 후속 실험을 제안했습니다.”
